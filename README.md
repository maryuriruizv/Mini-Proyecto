# MINI PROYECTO

## Descripcion
Este repositorio corresponde a un **mini proyecto de mascotas**. Donde permite registrar su nombre, edad, y peso utilizando arreglos. Ademas, incluye validaciondes de entrada, busqueda de registro y un componente creativo en la cual coinsiste en dar una recomendacion de acuerdo a su peso y tamaño de cada mascota.

## Objetivo del repositorio
Su objetivo es administrar un registro básico de mascotas utilizando estructuras de control fundamentales, arreglos paralelos y funciones modulares.

## Contenido del mini proyecto
- logica y resolucion de problemas
- variables, operadores entrada/salida
- bucles
- arreglos
- funciones y modularizacion
  
## Estructura del repositorio
- Registrar Mascota: Captura y valida los datos de entrada.

- Mostrar Mascotas: Recorre los arreglos en paralelo para imprimir la lista.

- Buscar Mascota: Localiza registros por coincidencia de texto.

- Componente Nutricional: Ejecuta la lógica del módulo creativo basado en el peso.
  
## Metodologia de trabajo
- Análisis y Definición de Requerimientos.
- Diseño de la Interfaz y Estructura de Control.
- Implementación Modular.
- Pruebas y Depuración.
- Commits utilizando Git y GitHub.
